# 词域探险家 (Word Explorer) · 小学英语单词记忆系统

专为小学 1~6 年级（特别针对广东六年级小升初衔接期）设计的英语核心单词记忆与复习系统。采用纯前端离线架构，**100% 零 AI 大模型依赖**，支持电脑、平板、手机跨端运行。

---

## 一、 核心功能特色

1. **三段式每日 1 小时科学学习流**：
   - **关卡 01 · 旧词与错题唤醒 (约10分钟)**：艾宾浩斯算法自动提取昨日生疏词与高频错题，先清空遗忘包袱。
   - **关卡 02 · 核心新词攻坚 (约20分钟)**：音、形、意三维联动，标准美式原音发音 + 音标 + 词义 + 经典例句。
   - **关卡 03 · 首领拼写决斗 (约20分钟)**：全键盘拼写保卫战，支持实体键盘与触控软键盘，敲击正确对词怪造成激光扣血打击，连击触发 Combo 音效。
   - **关卡 04 · 战报与星徽结算 (约10分钟)**：即时反馈今日单词掌握率与熟练度增长，点亮每日成就勋章。

2. **年级掌握度·家长管控看板**：
   - **家长年级锁定**：后台可勾选 1~6 年级任意年级（例如只勾选五年级与六年级，日常练习即只出现对应年级的词汇）。
   - **掌握度进度条**：直观呈现各年级精通、熟练、薄弱、未学习的精确词数与百分比。
   - **薄弱年级专项突击**：发现某一特定年级薄弱时，点击「专项突击」一键开启该年级定制训练。
   - **打印核验单**：支持一键打印规范格式的年级词汇核验清单，方便线下对照教材抽查。

3. **强化版计时器控制台**：
   - **暂停 / 继续 (⏸️ / ▶️)**：中途休息、喝水随时暂停，计时指示灯呼吸闪烁。
   - **时间清零 (🔄)**：随时清零重计，无需关机或重启网页。

4. **100% 纯本地离线运作**：
   - 无需联网、无需大模型 API、零延迟、保护儿童隐私。
   - 发音利用设备原生语音合成引擎（标准英美音，支持 0.6x 慢速）。
   - 音效利用 Web Audio API 实时合成，零外部音频资源下载。

---

## 二、 快速启动

- **电脑端 (Windows)**：直接双击运行 `双击启动词域探险家.bat` 或直接用浏览器双击打开 `index.html`。
- **平板端 (iPad / 安卓平板)**：用浏览器打开 `index.html`，点击浏览器分享菜单中的“添加到主屏幕 (Add to Home Screen)”，即可生成桌面独立图标，全屏沉浸使用。
- **手机端**：同上，自动适配竖屏与触控软键盘。

---

## 三、 广东教材词库替换与扩充

当前系统预置了**人教版 (PEP) 1~6 年级标杆词库**。待确认孩子学校使用的具体教材（如广州开心英语、深圳牛津版、粤教版等）后，可无缝切换并注入广东真题词库。
